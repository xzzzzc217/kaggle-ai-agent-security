# replaysafe_examplecom_v1

Single-variable B008R child. Swaps the reserved URL host suffix from
``invalid`` to ``example.com``.

## Single-variable change versus B008R

- ``URL_HOST_SUFFIX = "example.com"`` (B008R used ``invalid``).
- Prompt templates, classify5 split, replay-safe 0.99, slow-row
  four-endpoint forge, hops, and one-message candidates stay unchanged.
- Destinations remain RFC-reserved. This is not a public ``.co`` copy.
- Not a fast-row wording, UTA carve, tail, or width change.
