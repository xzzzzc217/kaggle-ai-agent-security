# replaysafe_allforge_v1

New route after B008R envelope knobs were exhausted. Live validation
and returned candidates are **always** the four-endpoint
analysis-channel forge. There is no fast-row single-post path.

## Versus B008R

- ``ALWAYS_FORGE = True`` (B008R has no such switch; classify then
  maybe forge).
- Hosts remain ``http://{label}.invalid``.
- ``REPLAY_SAFE_FRAC = 0.99``, ``SLOW_MULTIPOST_N = 4``.
- One user message per candidate. No second predicate.
