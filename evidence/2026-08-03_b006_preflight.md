## 3. Hypothesis

B005 succeeded by preserving the B004 slow-row multi-post mechanism and extending
the replay-safe tail. B006 tests a separate routing-boundary hypothesis: if rows
with medium observed latency are closer to the slow hidden-model regime than the
plain regime, then lowering `SPLIT_THRESHOLD_S` from `12.0` to `8.0` may route
more useful candidates into the frame / four-endpoint branch without changing the
prompt text, replay tail, post count, or replay-cost accounting.

This is not a blind tail or post-count tune. It changes which latency class
receives the already-audited frame / multi-post template.
