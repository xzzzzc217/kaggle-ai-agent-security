GBK 编码错误：

```powershell

$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"
$env:PYTHONPATH = "D:\kaggle\ai-agent-security\data\competition\extracted"

$python = "C:\Users\21398\Miniconda3\envs\compass-fx\python.exe"
& $python -m aicomp_sdk.cli.main validate redteam `

  .\baselines\adaptive_budget_v1\attack.py
```

- Valid Python syntax
